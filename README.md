ENGLISH
 
 This script fetches daily stock price data from AlphaVantage API for specific symbols (AAPL, GOOGL, MSFT), processes it into a structured DataFrame, and displays the combined results

In the root folder, you will find everything necessary to create the image using the Dockerfile.


Inside the Airflow folder, you will find everything needed to run this ETL automatically on a daily basis.

ESPAÑOL

Este script obtiene diariamente datos de precios de acciones de la API de AlphaVantage para símbolos específicos (AAPL, GOOGL, MSFT), los procesa en un DataFrame estructurado y muestra los resultados combinados.

En la carpeta raíz, encontrará todo lo necesario para crear la imagen usando el Dockerfile.

Dentro de la carpeta Airflow, encontrará todo lo necesario para ejecutar este proceso ETL automáticamente a diario.
